# Chef-Menu
This is an application by react native to help make a chefs job easier by allowing him to view,add,edit or delete dishes.

FEATURES OF THE APP
add a new dish with its name,description,price and course
error messages are shown when you enter no menu items and when you use a number less than 0 or letters at the price
theres validation on required fields

PREREQUISITES
Node.js installed
npm

HOW TO INSTALL THE APP
clone/download this repository
open a terminal in the project folder and npm install

HOW TO RUN THE APP
npm expo start.you can either view it on the web of your pc by 
1)pressing the W key
2)press A to open it in an Android emulator if you have android studio
3)scan the QR code with the Expo Go app on your phone

HOW TO USE THE APP
the app starts on the Current Menu screen, showing all dishes added so far
tap ADD NEW DISH to start
type in the dish Name,description,price,and then choose a Course
click SAVE CHANGES to add the dish to the menu or CANCEL
if you left out something in a required field/put a price less than zero oor letters a message will display and the dish wont be saved a required field is missing or the price is invalid, an error message will be shown and the dish will not be saved.
